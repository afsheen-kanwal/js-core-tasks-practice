# JavaScript Logic Building Challenges

A structured collection of foundational JavaScript programming challenges focusing on problem-solving, validation algorithms, utility functions, and text formatting.

## 🚀 Covered Concepts
This repository tracks practical assignments designed to practice core programming patterns:
* **String Manipulation:** Using `.trim()`, `.toUpperCase()`, `.toLowerCase()`, `.charAt()`, and `.concat()`.
* **Validation Control:** Data formatting pipelines like password strength rating and phone number structure matching.
* **Control Structures:** Implementing multi-branch conditional blocks (`if-else`) and incremental parsing `for` loops.
* **Functional Logic:** Utilizing basic math functions (`Math.round`, `Math.sqrt`) and nested inline Arrow functions.

## 📁 Project Directory
1. **Password Strength Checker:** Analyzes alphanumeric layout distributions via targeted char iteration.
2. **Smart Delivery System:** Dynamic rule engine tracking weather elements, transport conditions, and VIP pricing scales.
3. **Cinema Ticket Billing:** Multi-tier discount system evaluating bulk ticket configurations and group accounts.
4. **Mobile Number Validator:** Validates layout frameworks and enforces format prefixes.
5. **School Admission Slip Generator:** Concatenates form values into clean structural text receipts.

## 🛠️ Getting Started
To execute any challenge script locally, simply copy the code block and run it using Node.js:
```bash
node filename.js
```
